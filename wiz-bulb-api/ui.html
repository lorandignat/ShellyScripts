API

Bulbs are addressed by MAC, without separators: 9877d50abae0. Click the MAC under a card to copy it.

Lights

GET /bulbsAll known bulbs and categories. ?live=1 refreshes first.
GET /bulb/<mac>200 if the bulb answers right now, 503 if not.
POST /bulb/<mac>/toggleFlip power. Also /on and /off.
POST /bulb/<mac>/setsetPilot fields: dimming, temp, r/g/b, sceneId…
DELETE /bulb/<mac>Forget a bulb.

Categories

GET /categoriesCategories with bulb counts.
POST /categories{"name": "Bedroom"}
DELETE /categories/<id>Delete; bulbs become uncategorised.
POST /bulb/<mac>/category{"category": "<id>"} or null.
curl -s http://192.168.1.5:8077/bulbs
curl -s -X POST http://192.168.1.5:8077/bulb/9877d50abae0/toggle
curl -s -X POST http://192.168.1.5:8077/bulb/9877d50abae0/set \
     -d '{"dimming": 40, "temp": 2700}'

Known bulbs and categories are stored in /data/state.json. Add Authorization: Bearer <token> if WIZ_API_TOKEN is set.
